1 In the given figure: Prove that the two polygons $ABCD$ and $EFGH$ are similar and write the similarity ratio of polygon $ABCD$ to polygon $EFGH$.
📝 Student Answer & Proof:
Solution & Mathematical Proof Q1
  • In the two polygons $ABCD$ and $EFGH$: $$m(\angle A) = m(\angle E), \quad m(\angle B) = m(\angle F), \quad m(\angle C) = m(\angle G), \quad m(\angle D) = m(\angle H)$$
  • Calculating the ratios of the lengths of corresponding sides: $$\dfrac{AB}{EF} = \dfrac{12}{8} = \dfrac{3}{2}, \quad \dfrac{BC}{FG} = \dfrac{9}{6} = \dfrac{3}{2}, \quad \dfrac{CD}{GH} = \dfrac{6}{4} = \dfrac{3}{2}, \quad \dfrac{DA}{HE} = \dfrac{15}{10} = \dfrac{3}{2}$$
  • Since $\dfrac{AB}{EF} = \dfrac{BC}{FG} = \dfrac{CD}{GH} = \dfrac{DA}{HE} = \dfrac{3}{2}$ and corresponding angles are equal in measure: $$\therefore \text{Polygon } ABCD \sim \text{Polygon } EFGH$$
Similarity Ratio = 3/2

3 In the given figure: If polygon $ABCD \sim \text{polygon } EFGH$:
1 Find: $m(\angle C)$ and $m(\angle H)$.
2 Find the length of each of $\overline{FG}$ and $\overline{DC}$.
📝 Student Answer & Proof:
Solution & Mathematical Proof Q3
  • First: Since polygon $ABCD \sim \text{polygon } EFGH$: $$m(\angle A) = m(\angle E) = 90^\circ, \quad m(\angle B) = m(\angle F) = 120^\circ, \quad m(\angle C) = m(\angle G) = 45^\circ$$ $$m(\angle D) = m(\angle H) = 360^\circ - (90^\circ + 120^\circ + 45^\circ) = 105^\circ$$
  • Second: Since polygon $ABCD \sim \text{polygon } EFGH$: $$\dfrac{AB}{EF} = \dfrac{BC}{FG} \implies \dfrac{15\sqrt{3}}{5\sqrt{3}} = \dfrac{30}{FG} \implies FG = \dfrac{5\sqrt{3} \times 30}{15\sqrt{3}} = 10\text{ cm}$$ $$\dfrac{AB}{EF} = \dfrac{DC}{HG} \implies \dfrac{15\sqrt{3}}{5\sqrt{3}} = \dfrac{DC}{10\sqrt{2}} \implies DC = \dfrac{15\sqrt{3} \times 10\sqrt{2}}{5\sqrt{3}} = 30\sqrt{2}\text{ cm}$$
m(∠C) = 45°, m(∠H) = 105°, FG = 10 cm, DC = 30√2 cm
4 Self-Evaluation In the following figure: If polygon $ABCD \sim \text{polygon } EFGH$:
1 Find: $m(\angle C)$ and $m(\angle D)$.
2 Find the length of each of $\overline{FG}$ and $\overline{AD}$.
📝 Student Answer & Proof:
Solution & Mathematical Proof Q4
  • 1. Finding $m(\angle D)$ and $m(\angle C)$: Since polygon $ABCD \sim \text{polygon } EFGH$: $$m(\angle D) = m(\angle H) = 135^\circ$$ Since $m(\angle A) = 75^\circ$ and $m(\angle B) = 90^\circ$, the sum of interior angles of quadrilateral $ABCD$ is $360^\circ$: $$m(\angle C) = 360^\circ - (75^\circ + 90^\circ + 135^\circ) = 60^\circ$$
  • 2. Finding lengths of $\overline{FG}$ and $\overline{AD}$: From the similarity ratio of corresponding sides: $$\dfrac{AB}{EF} = \dfrac{BC}{FG} = \dfrac{CD}{GH} = \dfrac{AD}{EH}$$ Since $BC = 16\sqrt{2}\text{ cm}$ and similarity scale factor $k = 2$ (or using $GH = 4\sqrt{2}\text{ cm}$ and $EH = 8\sqrt{2}\text{ cm}$): $$AD = 2 \times EH = 2 \times 8\sqrt{2} = 16\sqrt{2}\text{ cm}, \quad FG = 8\sqrt{2}\text{ cm}$$
m(∠D) = 135°, m(∠C) = 60°, AD = 16√2 cm
5 In each of the following, prove that the two polygons are similar, and write the similarity ratio:
1 Rectangle $ABCD$ to rectangle $XYZM$.
2 Rhombus $ABCD$ to rhombus $EFGH$.
📝 Student Answer & Proof:
Solution & Mathematical Proof Q5
  • 1. Rectangle $ABCD$ to rectangle $XYZM$: All interior angles of both rectangles equal $90^\circ$. $$\dfrac{BC}{YZ} = \dfrac{6}{3} = 2, \quad \dfrac{CD}{ZM} = \dfrac{4}{2} = 2 \implies \dfrac{BC}{YZ} = \dfrac{CD}{ZM} = 2$$ $$\therefore \text{Rectangle } ABCD \sim \text{Rectangle } XYZM \quad (\text{Similarity Ratio } = 2)$$
  • 2. Rhombus $ABCD$ to rhombus $EFGH$: In rhombus $ABCD$: $m(\angle C) = 180^\circ - 110^\circ = 70^\circ = m(\angle G)$, and $m(\angle D) = m(\angle H) = 110^\circ$. Ratio of sides: $$\dfrac{AB}{EF} = \dfrac{BC}{FG} = \dfrac{CD}{GH} = \dfrac{DA}{HE} = \dfrac{3}{5}$$ $$\therefore \text{Rhombus } ABCD \sim \text{Rhombus } EFGH \quad \left(\text{Similarity Ratio } = \dfrac{3}{5}\right)$$
Part 1 Ratio = 2, Part 2 Ratio = 3/5
6 Self-Evaluation In each of the following, prove that the two polygons are similar, and write the similarity ratio:
1 Square $ABCD$ to square $LMNO$.
2 Parallelogram $ABCD$ to parallelogram $PQRS$.
📝 Student Answer & Proof:
Solution & Mathematical Proof Q6
  • 1. Square $ABCD$ to square $LMNO$: All interior angles of both squares are $90^\circ$, and all sides of each square are equal: $$\dfrac{AB}{LM} = \dfrac{BC}{MN} = \dfrac{CD}{NO} = \dfrac{DA}{OL} = \dfrac{15}{6} = \dfrac{5}{2}$$ $$\therefore \text{Square } ABCD \sim \text{Square } LMNO \quad \left(\text{Similarity Ratio } = \dfrac{5}{2}\right)$$
  • 2. Parallelogram $ABCD$ to parallelogram $PQRS$: In parallelogram $ABCD$: $m(\angle A) = 180^\circ - 120^\circ = 60^\circ = m(\angle P)$, and $m(\angle B) = m(\angle Q) = 120^\circ$. $$\dfrac{AB}{PQ} = \dfrac{8}{6} = \dfrac{4}{3}, \quad \dfrac{AD}{PS} = \dfrac{6}{4.5} = \dfrac{4}{3}$$ $$\therefore \text{Parallelogram } ABCD \sim \text{Parallelogram } PQRS \quad \left(\text{Similarity Ratio } = \dfrac{4}{3}\right)$$
Part 1 Ratio = 5/2, Part 2 Ratio = 4/3
7 In the given figure: If polygon $ABCD \sim \text{polygon } EFGH$, and $\dfrac{\text{Perimeter of polygon } ABCD}{\text{Perimeter of polygon } EFGH} = \dfrac{3}{2}$, find the value of each of: $x$, $y$, and $z$.
📝 Student Answer & Proof:
Solution & Mathematical Proof Q7
  • Since polygon $ABCD \sim \text{polygon } EFGH$ and $\dfrac{\text{Perimeter of } ABCD}{\text{Perimeter of } EFGH} = \dfrac{3}{2}$: $$\dfrac{AB}{EF} = \dfrac{BC}{FG} = \dfrac{CD}{GH} = \dfrac{3}{2}$$
  • Finding $z$: $$\dfrac{AB}{EF} = \dfrac{3}{2} \implies \dfrac{6}{z} = \dfrac{3}{2} \implies z = \dfrac{2 \times 6}{3} = 4$$
  • Finding $y$: $$\dfrac{BC}{FG} = \dfrac{3}{2} \implies \dfrac{y + 3}{5} = \dfrac{3}{2} \implies y + 3 = 7.5 \implies y = 7.5 - 3 = 4.5$$
  • Finding $x$: $$\dfrac{CD}{GH} = \dfrac{3}{2} \implies \dfrac{2x + 1}{x + 2} = \dfrac{3}{2} \implies 4x + 2 = 3x + 6 \implies x = 4$$
x = 4, y = 4.5, z = 4
8 Self-Evaluation In the following figure: If polygon $ABCD \sim \text{polygon } EFGH$, and $\dfrac{\text{Perimeter of } ABCD}{\text{Perimeter of } EFGH} = \dfrac{3}{4}$, find the value of each of $x$, $y$, and $z$.
📝 Student Answer & Proof:
Solution & Mathematical Proof Q8
  • Since polygon $ABCD \sim \text{polygon } EFGH$ and $\dfrac{\text{Perimeter of } ABCD}{\text{Perimeter of } EFGH} = \dfrac{3}{4}$: $$\dfrac{AB}{EF} = \dfrac{BC}{FG} = \dfrac{CD}{GH} = \dfrac{3}{4}$$
  • Finding $x$: $$\dfrac{BC}{FG} = \dfrac{3}{4} \implies \dfrac{x + 1}{2x} = \dfrac{3}{4} \implies 6x = 4x + 4 \implies 2x = 4 \implies x = 2$$
  • Finding $y$: $$\dfrac{CD}{GH} = \dfrac{3}{4} \implies \dfrac{4.5}{2y} = \dfrac{3}{4} \implies 6y = 18 \implies y = 3$$
  • Finding $z$: $$\dfrac{AB}{EF} = \dfrac{3}{4} \implies \dfrac{2z - 3}{8} = \dfrac{3}{4} \implies 2z - 3 = 6 \implies 2z = 9 \implies z = 4.5$$
x = 2, y = 3, z = 4.5

10 In the following figure: If rectangle $ABCD \sim \text{rectangle } EFGH$, what is the value of $x$?
📝 Student Answer & Proof:
Solution & Mathematical Proof Q10

Solution & Mathematical Proof Q11

  • Since parallelogram $ABCD \sim \text{parallelogram } KLMN$: $$m(\angle M) = m(\angle C) = 50^\circ \implies x = 50$$
Correct Answer: (a) 50
12 In the following figure: If $\dfrac{\text{Perimeter of square } ABCD}{\text{Perimeter of square } XYZM} = \dfrac{3}{2}$, what is the area of square $XYZM$?
📝 Student Answer & Proof:
Solution & Mathematical Proof Q12
  • Since any two squares are similar, the ratio of their perimeters equals the ratio of their side lengths: $$\dfrac{BC}{YZ} = \dfrac{3}{2} \implies \dfrac{6}{YZ} = \dfrac{3}{2} \implies YZ = \dfrac{6 \times 2}{3} = 4\text{ cm}$$
  • Area of square $XYZM = (YZ)^2 = 4^2 = 16\text{ cm}^2$.
Correct Answer: (c) 16 cm²
13 In the following figure: If rhombus $ABCD \sim \text{rhombus } HLKJ$, what is the value of $x$?
📝 Student Answer & Proof:
Solution & Mathematical Proof Q13
  • In rhombus $HLKJ$, consecutive angles are supplementary: $$m(\angle L) = 180^\circ - m(\angle K) = 180^\circ - 60^\circ = 120^\circ$$
  • Since rhombus $ABCD \sim \text{rhombus } HLKJ$: $$m(\angle B) = m(\angle L) \implies 2x = 120 \implies x = 60$$
Correct Answer: (a) 60
14 In the following figure: If polygon $ABCD \sim \text{polygon } EBHG$, what is the value of $x$?
📝 Student Answer & Proof:
Solution & Mathematical Proof Q14
  • Since polygon $ABCD \sim \text{polygon } EBHG$: $$\dfrac{AB}{EB} = \dfrac{CD}{HG}$$
  • Substitute $AB = x + 5$, $EB = 5\text{ cm}$, $CD = 6\text{ cm}$, and $HG = 4\text{ cm}$: $$\dfrac{x + 5}{5} = \dfrac{6}{4} \implies x + 5 = \dfrac{5 \times 6}{4} = 7.5 \implies x = 7.5 - 5 = 2.5\text{ cm}$$
Correct Answer: (b) 2.5
15 Two similar polygons, the ratio between the lengths of two corresponding sides is $2 : 3$, and the perimeter of the smaller polygon is $34\text{ cm}$. What is the perimeter of the larger polygon?
📝 Student Answer & Proof:
Solution & Mathematical Proof Q15
  • The ratio between the perimeters of two similar polygons equals the ratio between the lengths of any two corresponding sides: $$\dfrac{\text{Perimeter of smaller polygon}}{\text{Perimeter of larger polygon}} = \dfrac{2}{3}$$
  • Given the perimeter of the smaller polygon is $34\text{ cm}$: $$\dfrac{34}{\text{Perimeter of larger polygon}} = \dfrac{2}{3} \implies \text{Perimeter of larger polygon} = \dfrac{34 \times 3}{2} = 51\text{ cm}$$
Correct Answer: (c) 51 cm
